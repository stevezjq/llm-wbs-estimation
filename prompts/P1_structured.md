【估算口径】
- 单位为人时（person-hour），指完成该工作包的净人工投入。
- `hours` 为最可能值，不含风险缓冲、管理缓冲和返工预留。

3. 同一功能允许拆成多个工作包，不要求与功能条目一一对应。
4. 只覆盖需求中真实存在的工作，不臆造需求之外的功能。

【输出格式】
只输出一个合法 JSON 对象，不要输出解释性文字，不要使用 Markdown 代码围栏。
